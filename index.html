RoyaleTracker.gg

Clash Royale statistics · live since January 2026

Built with Angel Tonov (@MrFann1)

Player and clan profiles, leaderboards, and the best decks for every arena, card and game mode. Every ranking on the site is computed from our own battle-data pipeline, which polls the official Clash Royale API around the clock.

887K+battles collected per day
38M+battles stored (45-day window)
184card pages with live deck rankings
300+pages in the sitemap

Figures measured in October 2026.

  • A battle pipeline that replaced scraping. A long-running crawler keeps a pool of active players, polls their battle logs, deduplicates each battle seen from both sides and classifies it by game mode. A nightly job folds raw battles into weekly aggregates, and a separate verifier recomputes every aggregate from the raw table.
  • Rankings that resist noise and abuse. Decks are ranked by the Wilson score lower bound of their win rate with a battle floor, and the exports filter out trophy-dumping decks and the decks that farm wins off them.
  • Production incidents with lasting fixes: IP-bound API keys that revoked each other across machines, cached error pages replayed after an outage, and a disk that filled up with Next.js page caches. Each one now has a guard or a monitor.
  • AI deck tools on the Anthropic Claude API: a deck builder that recommends decks from the cards a player owns, and a deck rater, with daily usage limits counted in PostgreSQL.
  • SEO built into the code: structured data generated from the same values as the visible page, one canonical URL helper, generated share images and real 404 / 410 responses, all checked by a script.

BrawlMetrics.gg

Brawl Stars statistics · live since July 2026

Built with Angel Tonov

Player and club profiles, 108 brawler pages, map pages for every mode, tier lists and leaderboards. Its pipeline aggregates battles at ingest: each battle updates per-brawler, matchup, teammate and team-comp counters and is then discarded, which keeps the database small.

1.45M+battles processed per day
93M+battles counted since August 2026
16.7Mplayers indexed
390+pages in the sitemap
  • Adaptive rate limiting: the poller runs at 30 requests per second, halves its rate on any HTTP 429 and recovers gradually, so it stays close to the API limit without being blocked.
  • Sample-size gates: below 300 games for a ranking or 100 for a matchup, the API returns "insufficient data" instead of a misleading percentage.
  • Fixing a page type that always failed: brawler pages took 16 to 18 seconds against a 10-second budget. Single-flight caching and memoisation brought the endpoint to about 1 second.
